# .NET Assignment

## 📄 Description

This repository contains a collection of **C# and .NET Framework** lab programs covering core programming concepts — from control structures and arrays to object-oriented programming, exception handling, delegates, Windows Forms, and database connectivity.

Each folder is named according to the concept it demonstrates and contains the corresponding project files.

## ⚙️ Requirements

- Visual Studio (2019 or later recommended)
- .NET Framework / .NET SDK
- SQL Server (for the CRUD / Student Registration System program)

## ▶️ How to Run

1. Clone the repo:
   ```
   git clone https://github.com/Itssuraj-1/dotnet-assignment-suraj-thapa-.git
   ```

2. Open the `.slnx` solution file (`dotnet assignment(suraj thapa).slnx`) in Visual Studio.

3. Select the desired project folder, set it as the startup project, and run (F5).

4. For the CRUD program, update the SQL Server connection string to match your local database before running.

## ✅ Conclusion

This lab session provided practical exposure to the fundamental concepts of C# and .NET Framework programming, ranging from basic control structures to object-oriented principles and database connectivity. Through the successful implementation of the programs listed above, a clear understanding of conditional statements, arrays, string handling, OOP concepts, exception handling, delegates, Windows Forms, and database operations was achieved.

1. **Grade using Else If Ladder** — Displays a student's grade based on percentage using nested else-if conditions, demonstrating how conditional branching selects the correct output from multiple ranges.
2. **Menu Driven Calculator using Switch** — Performs basic arithmetic operations (addition, subtraction, multiplication, division) based on user choice, demonstrating the use of switch-case for menu-driven logic.
3. **Maximum & Minimum of 10 Numbers** — Accepts 10 numbers into an array and correctly identifies the maximum and minimum values, demonstrating array traversal and comparison logic.
4. **Sort Array in Ascending Order** — Uses the bubble sort technique to arrange array elements in ascending order, demonstrating basic sorting algorithm implementation.
5. **Count Vowels in String** — Accepts a string and accurately counts the number of vowels, demonstrating string traversal and character comparison.
6. **Constructor Overloading (Rectangle Class)** — Implements multiple constructors in the Rectangle class to initialize objects differently, demonstrating how constructor overloading provides flexibility in object creation.
7. **Method Overloading (Area Calculation)** — Implements different area calculation methods with the same name but different parameters, demonstrating how method overloading allows a single method name to handle multiple shapes.
8. **Inheritance (Vehicle → Car & Bike)** — The Car and Bike classes inherit properties and methods from the base Vehicle class, demonstrating code reusability through inheritance.
9. **Method Overriding (virtual & override)** — The Dog and Cat classes override the base Animal class's method using virtual and override keywords, demonstrating runtime polymorphism.
10. **Divide by Zero Exception Handling** — Safely handles divide-by-zero errors using try-catch blocks, demonstrating proper exception handling to prevent program crashes.
11. **Delegate (Maximum & Minimum)** — Uses a delegate to reference methods that calculate the maximum and minimum of two numbers, demonstrating how delegates provide flexible method referencing.
12. **Windows Forms Calculator** — A form-based calculator designed using Windows Forms, allowing users to perform basic arithmetic operations through a graphical interface, demonstrating event-driven GUI programming.
13, 14. **CRUD Operation using Windows Forms + SQL** — The Student Registration System performs Insert, Update, and Delete operations connected to a SQL database, demonstrating database connectivity and CRUD functionality in a Windows Forms application.
